FLOW / SESSION REPORT SAMPLE

変更の説明を、文章と図で伝える

完了レポートに図の選択基準を追加しました。各変更を短い文章で説明し、必要に応じて複数の図で構造や流れを補います。

対象：flow-session-report の指示・HTMLテンプレート ｜ 2026年11月21日

構成・表現を参照するための保存済みサンプルです。レポート生成ルールを変更した時点の差分を題材にしています。実装commit・Implement review cycle・完了チェックポイントは未作成です。

できるようになったこと

レポートを読む人が、変更の要点を文章でつかみ、図で関係や前後の違いを確認できるように、生成ルールを整えました。図の種類や枚数は、変更の内容に合わせて選びます。

変更前と変更後

01　変更内容に合わせて図を選ぶ

従来は図の種類を選ぶ基準がなく、テンプレートも箇条書きの前後比較が中心でした。今回は、処理・状態・責務など、説明したい関係に合う図を選ぶ指示を追加しました。

同じ変更を、選択基準の対応図でも示します。上の図は「どの順序でまとめるか」、下の図は「何を説明するときにどの図を使うか」を表します。

02　一つの変更を、必要な数の図で説明する

変更が複数ある場合は目的ごとに分けます。一つの変更にも、構成図とシーケンス図のように観点の異なる図を組み合わせられます。図ごとに短い説明を添え、同じ内容の重複は避けます。

03　図を使わない場合も、文章で簡潔に伝える

文言修正など、図が理解に寄与しない変更は文章だけで説明できます。図の有無にかかわらず各変更の説明文は必須です。また、変更前の根拠が不足する場合は、その不足を明記し、関係を推測で描かないようにしました。

主な判断と理由

文章を必須にし、図の数は固定しない

利用者から「複数の変更」「一つの変更に複数の図」「簡潔な文章による説明」が必要という要望を受け、文章を土台に、必要な図を組み合わせる指示にしました。

前後の図は同じ条件で比較する

変更前後の違いを読み取りやすくするため、比較の組ごとに図の種類・粒度・用語・向きを揃えます。追加・削除・移動は文字や枠線でも区別します。

HTML/CSSだけで読める形式を維持する

既存の方針を引き継ぎ、図とスタイルはHTMLに同梱します。外部アセットやJavaScriptを使わず、ファイルを開くだけで読めます。
